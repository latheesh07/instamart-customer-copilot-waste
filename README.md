# Instamart Customer Intelligence & Support Copilot

## Project Overview
This project demonstrates customer analytics, customer segmentation, support ticket classification, policy retrieval, and refund request tracking using synthetic data.

## Project Parts
- Part A: Data Foundation — Clean, Store, Query
- Part B: Customer Segments and Lapse Prediction
- Part C: Support Ticket Triage with Guardrails
- Part D: Policy RAG Assistant and Refund Agent

## Technologies
- Python
- Pandas
- SQLite
- Scikit-learn
- Streamlit

## Data Notice
This project uses synthetic demonstration data and fictional policy examples. It does not use real Instamart customer data or process actual refunds.

## Project Status
The repository is under development. Features and test coverage may be incomplete.

## Run Locally
Install the dependencies:

    pip install -r requirements.txt

Start the Streamlit application:

    streamlit run app.py
